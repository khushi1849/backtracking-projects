# Backtracking Projects

Two classic backtracking problems, solved in C++ and ported to JavaScript so they run in the browser.

## Projects

### Sudoku Solver
Fills in any Sudoku puzzle. Started with plain backtracking, then optimized with bitmasks and the MRV heuristic, and benchmarked all three versions on a hard puzzle.

- Live demo: https://khushi1849.github.io/backtracking-projects/sudoku-solver/
- Code: [sudoku-solver](sudoku-solver)

### N-Queens Solver
Places N queens on an N x N board so none attack each other. Columns and both diagonals are tracked, so each safety check takes constant time. The web version lets you enter any board size (1 to 12) and browse every valid solution.

- Live demo: https://khushi1849.github.io/backtracking-projects/n-queens/
- Code: [n-queens](n-queens)
